# Música de fundo

Formato: `.mp3` (mais compatível entre Android/iOS/web/desktop pro
`audioplayers`). Arquivos loopáveis, tocam em `ReleaseMode.loop`.

- `exploration_theme.mp3` — tema ambiente, toca em todas as telas fora
  do Combate (Habilidades, Colheita, Itens, Mapas, Ferramentas, Conta)
- `combat_theme.mp3` — tema mais intenso, toca só na tela de Combate

`_reserved/` guarda faixas já baixadas mas sem contexto definido ainda
(não registradas no `pubspec.yaml`, não entram no bundle do app):
- `_reserved/calm_theme.mp3` (era "calma que gostei.mp3") — guardada
  para um contexto futuro além de exploração/combate (ex.: tela de
  conquistas ou level up), 2026-08-08

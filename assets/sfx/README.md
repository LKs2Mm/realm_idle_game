# Efeitos sonoros

Formato: `.mp3`. Curtos, tocam uma vez (`ReleaseMode.release`),
sobrepostos entre si sem cortar um ao outro.

- `harvest_complete.mp3` — ciclo de colheita concluído
- `combat_hit.mp3` — golpe durante o combate
- `combat_victory.mp3` — vitória de combate
- `level_up.mp3` — level up de habilidade ou classe
- `craft_complete.mp3` — criação concluída (equipamento, poção, magia,
  processamento)
- `tool_upgrade.mp3` — compra/melhoria de ferramenta
- `tab_switch.mp3` — navegação entre abas (opcional, discreto)
- `action_blocked.mp3` — ação bloqueada (ex.: nível insuficiente)
